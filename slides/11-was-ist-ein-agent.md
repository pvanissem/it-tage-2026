# Ein Agent antwortet nicht nur.
Er arbeitet mit Werkzeugen.

Beispiel: „Erkläre dieses Repo und finde heraus, wie ich die Tests lokal starte.“

## Karten

### Auftrag

Ziel: Testweg finden. Noch nichts ändern.

### Kontext

README und Build-Dateien lesen

### Werkzeuge

Testkonfiguration im Repo suchen

### Rückmeldung

Testbefehl nennen und offene Fragen markieren

## Kernaussage

Das Modell wählt Schritte. Welche Werkzeuge der Agent nutzen darf, bestimmt die Umgebung.

## Sprechernotizen

Lofi erklärt ohne vorausgesetztes Agentenwissen: Das Modell entscheidet über nächste Schritte; Tools verbinden es mit Dateien, Tests oder Diensten. Der Kreislauf kann mehrfach durchlaufen werden. Nicht alle Aufgaben erfordern schreibende Tools. Ein Agent ist kein deterministischer, fehlerfreier Automatisierungsprozess.
