# Eine Sandbox ersetzt keine Freigabe

## Karten

### Was das Profil regelt

Auf welche Dateien der Agent zugreifen kann
Welche Netzwerkziele erreichbar sind

### Was die Organisation regelt

Welche Daten und Anwendungsfälle erlaubt sind
Wer betreibt, prüft und freigibt

## Kernaussage

Auch innerhalb der gesetzten Grenzen kann der Agent fachlich falsche Änderungen vorschlagen.
